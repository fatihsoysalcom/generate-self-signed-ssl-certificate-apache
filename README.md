# Generate Self-Signed SSL Certificate Apache

This bash script generates a self-signed SSL certificate and configures Apache on Ubuntu 20.04 to use it. It's suitable for development or testing environments.

## Language

`bash`

## How to Run

1. Save the code as `generate_ssl.sh`.
2. Make it executable: `chmod +x generate_ssl.sh`.
3. Run it with sudo: `sudo ./generate_ssl.sh`.
4. Replace `your_domain.com` with your actual domain or IP.
